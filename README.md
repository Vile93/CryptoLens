# CryptoLens

Анализ криптовалютных пар с техническими индикаторами и синхронизированными графиками на основе Binance API.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Возможности

- MA, MACD, MFI индикаторы
- Синхронизация масштаба между графиками
- Поддержка 1м, 5м, 15м, 1ч, 4ч, 1д интервалов
- WebSocket реалтайм обновления + REST историческая загрузка
- Адаптивный мобильный дизайн
- Сохранение настроек в localStorage

## Технологический стек

React 18, TypeScript, Vite, Tailwind CSS, Zustand, Lightweight Charts, Binance Public API

## Команды

```bash
npm run dev      # Разработка
npm run build    # Продакшн сборка
npm run lint     # Линтирование
```

## Ограничения

- Максимум 1000 свечей
- WebSocket передает только 1м свечи (агрегирует на клиенте)
- Публичный API Binance без аутентификации
